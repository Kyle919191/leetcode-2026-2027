==================================================
Optimal solution (Hash Set) - O(n) time, O(n) space

def contains_duplicate_sol1(nums: list[int]) -> bool:
    seen = set()
    for x in nums:
        # TODO-TALK: If this value is already in the set, I found a duplicate.
        if x in seen:
            return True
        # TODO-TALK: First time seeing this value, so I store it.
        seen.add(x)
    return False

Why it works:
- A set supports average O(1) membership checks.
- First time you see a value, add it.
- If value appears again, it is already in the set, so duplicate exists.

[ARRAY] LeetCode 242 - Valid Anagram
==================================================
Optimal solution (Frequency Count) - O(n) time, O(1) space for fixed alphabet

def is_anagram_sol1(s: str, t: str) -> bool:
    if len(s) != len(t):
        # TODO-TALK: Different lengths can never be anagrams.
        return False
    count = {}
    for ch in s:
        # TODO-TALK: Build frequency counts from the first string.
        count[ch] = count.get(ch, 0) + 1
    for ch in t:
        # TODO-TALK: If t has a character missing from s, it fails immediately.
        if ch not in count:
            return False
        count[ch] -= 1
        # TODO-TALK: Negative means t used this character too many times.
        if count[ch] < 0:
            return False
    return True

Why it works:
- Anagrams must have exactly same character counts.
- First loop adds counts from s; second loop subtracts counts using t.
- Any missing/negative count means mismatch.
- Equal length + all counts balanced implies anagram.

[ARRAY] LeetCode 49 - Group Anagrams
==================================================
Optimal solution (26-char frequency tuple key) - O(m*n), m words, n avg length

def group_anagrams_sol1(strs: list[str]) -> list[list[str]]:
    groups = {}
    for word in strs:
        freq = [0] * 26
        for ch in word:
            # TODO-TALK: Map each letter to 0..25 and increment its bucket.
            freq[ord(ch) - ord('a')] += 1
        # TODO-TALK: Tuple makes this signature hashable for dictionary keys.
        key = tuple(freq)
        # TODO-TALK: Words with the same signature go into the same group.
        groups.setdefault(key, []).append(word)
    return list(groups.values())

Why it works:
- Two strings are anagrams iff all 26 letter frequencies match.
- Frequency vector is an anagram-invariant signature.
- Same key => same bucket/group.

[ARRAY] LeetCode 347 - Top K Frequent Elements
==================================================
Most optimal common solution (Bucket by frequency) - O(n) time, O(n) space

def top_k_frequent_sol1(nums: list[int], k: int) -> list[int]:
    freq = {}
    for x in nums:
        # TODO-TALK: Count frequency of each number first.
        freq[x] = freq.get(x, 0) + 1

    # TODO-TALK: buckets[f] stores all numbers that appear exactly f times.
    buckets = [[] for _ in range(len(nums) + 1)]
    for num, f in freq.items():
        buckets[f].append(num)

    res = []
    for f in range(len(buckets) - 1, 0, -1):
        # TODO-TALK: Scan from high frequency to low to collect top k quickly.
        for num in buckets[f]:
            res.append(num)
            if len(res) == k:
                return res
    return res

Why it works:
- Max possible frequency is n, so we can index buckets by frequency.
- Put each number into bucket[freq].
- Scan buckets from high to low freq and collect first k numbers.

Note:
- Another common approach is min-heap O(n log k), but bucket achieves linear time.

[ARRAY] LeetCode 271 (Premium) - Encode and Decode Strings
==================================================
Optimal robust pattern (Length-prefixed encoding)

class CodecSol1:
    def encode(self, strs: list[str]) -> str:
        out = []
        for s in strs:
            # TODO-TALK: Encode each string as "<length>#<content>".
            out.append(str(len(s)))
            out.append('#')
            out.append(s)
        return ''.join(out)

    def decode(self, s: str) -> list[str]:
        res = []
        i = 0
        while i < len(s):
            j = i
            # TODO-TALK: Move j to separator to parse the length prefix.
            while s[j] != '#':
                j += 1
            length = int(s[i:j])
            # TODO-TALK: Read exactly "length" chars after '#'.
            word = s[j + 1:j + 1 + length]
            res.append(word)
            i = j + 1 + length
        return res

Why it works:
- We store each string as: "<length>#<content>".
- During decode, read length first, then read exactly that many chars.
- Works even if content contains '#', spaces, or empty strings.

[ARRAY] LeetCode 238 - Product of Array Except Self
==================================================
Optimal solution (Prefix + Suffix, no division) - O(n) time, O(1) extra output-excluded space

def product_except_self_sol1(nums: list[int]) -> list[int]:
    n = len(nums)
    res = [1] * n

    prefix = 1
    for i in range(n):
        # TODO-TALK: res[i] gets product of all numbers strictly to the left.
        res[i] = prefix
        prefix *= nums[i]

    suffix = 1
    for i in range(n - 1, -1, -1):
        # TODO-TALK: Multiply by product of all numbers strictly to the right.
        res[i] *= suffix
        suffix *= nums[i]

    return res

Why it works:
- First pass stores product of all elements left of i.
- Second pass multiplies product of all elements right of i.
- left_product * right_product = product except self.

[ARRAY] LeetCode 36 - Valid Sudoku
==================================================
Optimal solution (Track rows, cols, boxes with sets)

def is_valid_sudoku_sol1(board: list[list[str]]) -> bool:
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]

    for r in range(9):
        for c in range(9):
            val = board[r][c]
            if val == '.':
                continue
            b = (r // 3) * 3 + (c // 3)
            # TODO-TALK: Any repeat in row, column, or box makes board invalid.
            if val in rows[r] or val in cols[c] or val in boxes[b]:
                return False
            # TODO-TALK: Otherwise I record this digit in all three trackers.
            rows[r].add(val)
            cols[c].add(val)
            boxes[b].add(val)
    return True

Why it works:
- Sudoku validity means no repeated digit in any row, column, or 3x3 box.
- Sets enforce uniqueness for each constraint independently.
- Any repeat detected immediately => invalid board.

[ARRAY] LeetCode 128 - Longest Consecutive Sequence
==================================================
Optimal solution (Hash Set starts only) - O(n) average time, O(n) space

def longest_consecutive_sol1(nums: list[int]) -> int:
    num_set = set(nums)
    best = 0

    for x in num_set:
        # TODO-TALK: Only start counting from sequence starts.
        if x - 1 in num_set:
            continue
        cur = x
        length = 1
        # TODO-TALK: Expand forward while consecutive values exist.
        while cur + 1 in num_set:
            cur += 1
            length += 1
        best = max(best, length)
    return best

Why it works:
- Only start counting at sequence starts (x-1 not present).
- Each element is expanded at most once across all sequences.
- Avoids repeated work that sorting or naive scan would do.

[SLIDING WINDOW] LeetCode 121 - Best Time to Buy and Sell Stock
==================================================
Optimal solution (Track min price so far) - O(n) time, O(1) space

def max_profit_sol1(prices: list[int]) -> int:
    min_price = float('inf')
    best = 0
    for p in prices:
        # TODO-TALK: Keep best buy price seen so far.
        min_price = min(min_price, p)
        # TODO-TALK: Treat today as sell day and update max profit.
        best = max(best, p - min_price)
    return best

Why it works:
- For each day as sell day, best buy is minimum price before it.
- Keep running minimum and update max profit greedily.
- Single pass captures global optimum.

[SLIDING WINDOW] LeetCode 239 - Sliding Window Maximum
==================================================
Optimal solution (Monotonic Deque) - O(n) time, O(k) space

from collections import deque

def max_sliding_window_sol1(nums: list[int], k: int) -> list[int]:
    q = deque()  # stores indices, values decreasing
    res = []

    for i, x in enumerate(nums):
        # TODO-TALK: Remove indices that are outside the current window.
        while q and q[0] <= i - k:
            q.popleft()
        # TODO-TALK: Keep deque decreasing so front is always max index.
        while q and nums[q[-1]] <= x:
            q.pop()
        q.append(i)
        if i >= k - 1:
            # TODO-TALK: Window is formed, take value at deque front as max.
            res.append(nums[q[0]])
    return res

Why it works:
- Deque keeps candidate maxima in decreasing value order.
- Front always points to current window maximum index.
- Each index enters and leaves deque at most once => linear time.

[TWO POINTERS] LeetCode 11 - Container With Most Water
==================================================
Optimal solution (Two pointers from both ends) - O(n) time, O(1) space

def max_area_sol1(height: list[int]) -> int:
    left, right = 0, len(height) - 1
    best = 0
    while left < right:
        width = right - left
        h = min(height[left], height[right])
        best = max(best, width * h)
        if height[left] < height[right]:
            # TODO-TALK: Move shorter side hoping to find a taller boundary.
            left += 1
        else:
            right -= 1
    return best

Why it works:
- Area is limited by shorter wall.
- Moving the taller wall cannot improve min-height for same/less width.
- So move the shorter pointer, hoping to find a taller boundary.

[TWO POINTERS] LeetCode 42 - Trapping Rain Water
==================================================
Optimal solution (Two pointers with left_max/right_max) - O(n) time, O(1) space

def trap_sol1(height: list[int]) -> int:
    left, right = 0, len(height) - 1
    left_max, right_max = 0, 0
    water = 0

    while left < right:
        if height[left] < height[right]:
            # TODO-TALK: Left side is limiting now, so left position is decidable.
            left_max = max(left_max, height[left])
            water += left_max - height[left]
            left += 1
        else:
            # TODO-TALK: Right side is limiting now, so right position is decidable.
            right_max = max(right_max, height[right])
            water += right_max - height[right]
            right -= 1
    return water

Why it works:
- Water at index i is min(max_left, max_right) - height[i].
- If left side is lower, left_max is the limiting side now, so left is decidable.
- Symmetric logic when right side is lower/equal.
